# Triage labels

The engineering skills use five state roles. Apply the corresponding GitHub
label from this table.

| Role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer needs to evaluate the issue. |
| `needs-info` | `needs-info` | The reporter must provide more information. |
| `ready-for-agent` | `ready-for-agent` | The issue is fully specified for an AFK agent. |
| `ready-for-human` | `ready-for-human` | Human implementation or judgment is required. |
| `wontfix` | `wontfix` | The issue will not be actioned. |

Every triaged issue also carries exactly one category label: `bug` or
`enhancement`.
