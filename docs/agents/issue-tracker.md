# Issue tracker

Issues for this repository live in GitHub Issues at
`gnamikawa/dotfiles-nix`. Use the `gh` CLI to read and change them.

External pull requests are not an automatic triage surface. A pull request
may still be triaged when the maintainer names it explicitly.

GitHub shares one number sequence across issues and pull requests. Resolve an
explicit number against the named URL or use `gh pr view` before falling back
to `gh issue view` when its kind is unclear.

When a skill says to publish work to the issue tracker, create a GitHub issue.
Use GitHub sub-issues and native issue dependencies for wayfinder maps when
those features are available. Otherwise, record the relationship in the issue
body.
